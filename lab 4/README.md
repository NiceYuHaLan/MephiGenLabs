# Лабораторная работа № 4 — Эволюционная настройка контроллера робота в 2D-среде (проектная задача)

**Вариант 7**: эволюционная настройка контроллера робота в двумерной
симулированной среде. Собственный симулятор (unicycle-робот, сегментные
стены, 8 лучевых сенсоров через 2D-кросс-произведения), MLP-контроллер
8→6→2 (tanh, 62 веса). Сравнение двух алгоритмов при равном бюджете:
- **ГА** с вещественным кодированием (турнир k=3, BLX-α, гауссова мутация, элитизм 2);
- **ES (μ+λ)** (μ=10, λ=38, усечённый отбор);
- плюс ручной рефлексный baseline (Braitenberg-контроллер).
- Индивидуальные параметры: N = 18, Q = 2, Y = 26 → V = 7.

## Воспроизводимость

- Зерна серии: `seed = 11000 + 19·i`, i = 0…29 (30 запусков на метод).
- Бюджет запуска: 1900 вычислений фитнеса (~50 поколений по 38 оценок у обоих методов).
- Фитнес (максимизируется): прогресс к цели + 50 за касание цели − 50 за столкновение.
- Эпизод: до 300 шагов, досрочно — при столкновении или касании цели.

## Основные результаты

| Эксперимент | Метод | Лучший fit | Медиана | Std |
|---|---|---|---|---|
| ГА vs ES (30 запусков) | ГА (BLX-α) | **371.46** | **367.97** | 47.48 |
| | ES (μ+λ) | 371.23 | 169.47 | 119.17 |
| Ручной baseline | Braitenberg | 47.75 | — | — |

Оба метода в лучших запусках достигают цели без столкновений (максимум
≈ 380), но ГА стабильно воспроизводит результат (медиана 367.97), а
типичный запуск ES цели не достигает. Эволюционные контроллеры
превосходят ручной Braitenberg примерно в 7.8 раза.
