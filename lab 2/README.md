# Лабораторная работа № 2 — Генетический алгоритм для дискретной задачи с ограничениями

**Вариант 7**: распределение заявок между исполнителями с различной производительностью.
Представление — целочисленный вектор `x_i ∈ {0..5}` (исполнитель заявки i).
Цель — минимум makespan при ограничении ёмкости исполнителей (не более c_j заявок).
- N = 30 заявок (≥ 20 по ТЗ), M = 6 исполнителей (≥ 5), сумма ёмкостей 35 ≥ 30.
- Данные — синтетика с фиксированным зерном `seed = 746`.

## Основные результаты (makespan, чем меньше, тем лучше)

| Эксперимент | Конфигурация | лучшее | среднее | худшее |
|---|---|---|---|---|
| Обработка ограничения | штраф (W = 50) | 27.08 | 28.90 | 31.06 |
| | ремонт | 26.80 | **27.17** | 27.48 |
| Оператор рекомбинации | равномерный | 26.80 | 27.17 | 27.48 |
| | одноточечный | 26.72 | **27.00** | 27.41 |
| Базовые линии | жадная LPT | — | 33.69 | — |
| | случайный допустимый | 29.06 | 30.48 | — |
| | **ГА (одноточечный + ремонт)** | 26.72 | **27.00** | 27.41 |

- Ремонт лучше штрафа (27.17 vs 28.90 по среднему на 30 запусках): при штрафе
  популяция живёт с нарушениями, ремонт возвращает всех в допустимое множество.
- Одноточечный кроссовер немного точнее равномерного (27.00 vs 27.17).
- ГА устойчиво обыгрывает жадную LPT на ~20% и случайный допустимый поиск
  (30.48 vs 27.00).
- Лучшее решение: makespan 26.724, полностью допустимо —
  см. `results/best_solution.csv`, разбор по исполнителям — таблица 5 отчёта.
