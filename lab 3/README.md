# Лабораторная работа № 3 — Многокритериальная оптимизация: NSGA-II (трек A)

**Вариант 7, трек A**: распределение задач по исполнителям по трём критериям —
срок (makespan), дисбаланс нагрузки, стоимость. Метод — собственная реализация
NSGA-II (без библиотек): недоминируемая сортировка, расстояние до скопления,
элитизм через объединённый пул, внешний архив недоминируемых решений.
- N = 30 задач, M = 6 исполнителей, даные — синтетика с зерном `seed = 747`.
- Индивидуальные параметры: N = 18, Q = 2, Y = 26 → V = 7.

## Воспроизводимость

- Зерна серии: `seed = 9000 + 19·i`, i = 0…29 (30 запусков).
- Зерно данных задачи: `seed = 747`.
- Бюджет запуска: 20 000 вычислений вектора критериев.
- Гиперобъём: точный методом слайсинга; опорная точка 1.05 × max по общему
  архиву серии; контрольный пример (3 точки, HV = 7) проверяется в ноутбуке.
