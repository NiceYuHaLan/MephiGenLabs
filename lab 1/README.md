(ядро — Python из `../../venv`).

## Воспроизводимость

- Зерна ГПСЧ фиксированы: `seed = 7000 + 19·i`, i = 0…29 (30 независимых запусков на конфигурацию).
- Бюджет каждого запуска: 10 000 вычислений целевой функции (инициализация включительно).
- Все параметры алгоритма заданы константами в ноутбуке (раздел 2) и в таблице 2 отчёта.

## Основные результаты

| Конфигурация | лучшее f | среднее f | медиана | худшее f |
|---|---|---|---|---|
| ГА, σ = 0.05 | 3.14·10⁻⁸ | 2.88·10⁻⁷ | 2.11·10⁻⁷ | 8.44·10⁻⁷ |
| ГА, σ = 0.3 | 1.45·10⁻⁶ | 1.09·10⁻⁵ | 9.18·10⁻⁶ | 2.35·10⁻⁵ |
| ГА, σ = 1.0 | 1.54·10⁻⁵ | 1.00·10⁻⁴ | 8.98·10⁻⁵ | 2.20·10⁻⁴ |
| Случайный поиск | 0.960 | 1.98 | 1.85 | 3.73 |

- Во всех 90 запусках ГА сходится к глобальному минимуму (f* = 0);
  лучшая конфигурация (σ = 0.05) — со средней ошибкой координат < 10⁻³.
- Влияние масштаба мутации монотонно: разведку выполняет BLX-α кроссовер,
  поэтому мелкий шаг мутации (точная доводка) выигрывает; крупный шаг
  ограничивает точность ~10⁻⁴.
- Случайная выборка при равном бюджете хуже ГА на семь порядков.
